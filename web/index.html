Standard Professional Setup Guide

Step-by-step instructions to connect third-party AI clients and CLI tools.

1. OpenAI Python / Node.js SDK Setup

Point the official OpenAI client `base_url` to your local Python gateway:

from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:11434/v1",
    api_key="any-key"
)

response = client.chat.completions.create(
    model="moonshotai/kimi-k3-free",
    messages=[{"role": "user", "content": "Hello world"}]
)
print(response.choices[0].message.content)

2. Claude Code CLI Setup

Configure Claude Code (`~/.claude/settings.json`) to use the Gateway Anthropic endpoint:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:11434/v1",
    "ANTHROPIC_API_KEY": "omniroute-proxy"
  }
}

3. Cursor & Windsurf IDE Setup

In Cursor Settings > Models > OpenAI API Key & Base URL:

  • Override OpenAI Base URL: http://127.0.0.1:11434/v1
  • API Key: sk-gateway-local
